## 1. なぜ要るのか（根拠）

### 1.1 要求由来: ユーザが触れる箇所は全部多言語にする

利用者の指示（2026-08-28）:

> ゲームないのメッセージ、設定等の言語は全部多言語にして。ライセンスとかは日本語でいい。
> つまりゲームの中身として、ユーザが触れる点は多言語で。クレジットとか必要だから
> 入れてるものは別にいいてす。

したがって **境界は「ゲームの中身か、義務で置いてあるものか」**である。

| | 例 | 扱い |
|---|---|---|
| ゲームの中身 | HUD、ポーズ／設定、タイトル、演出文、アイテムの説明、暗証番号 UI、結末、ランク、3D 看板 | **5言語** |
| 義務で置くもの | クレジット画面（`#credits`）、`THIRD-PARTY-NOTICES.md`、`assets/fonts/OFL.txt` | **日本語のまま** |

### 1.2 要求由来: 現状、日本語以外では**パズルが解けない**

これは体裁の問題ではない。暗証番号の手掛かり3つは、すべて `src/game.js` の
日本語文字列の中にある（`src/game.js:40,46,53` の設計コメント）。

```
① マイナンバーカード …暗証番号は4桁。数字だけの、あれだ。
② e-Taxパスワードのメモ 『いつもの』と書いてある。…部屋に、何か落ちていなかったか。
③ FAKES 3種のギャグ 「同じ4桁を使い回している」「日付をそのまま並べただけ」
                     「日付は毎年、3月14日と15日に集中している」
```

3つ揃って初めて「いつもの4桁＝提出期限の日付」に辿り着く。英語・中国語・
ロシア語・スペイン語のプレイヤーは、この材料を1つも受け取れない。
書類の異変探しまでは遊べて、その先で必ず詰む。**現状は出荷できない。**

計測（2026-08-28）: 各ロケールのサブセットのうち、日本語 UI 由来だけの字が
en 414/516（80%）、ru 407/563（72%）、es 412/521（79%）。

## 2. 保証すること / しないこと

### 保証する

- `#credits` を除く、画面に出る全文言が5ロケール分そろっている
- **暗証番号の手掛かりが、そのロケールの正解と整合している**（§3.2。最重要）
- 日付・金額・氏名が、そのロケールの書式と設定で書かれている
- `src/ui.js` は純粋モジュール（DOM・three・localStorage・Math.random・Date を触らない）

### 保証しない

- 翻訳の自然さの母語話者レビュー。`anoms.js` と同じく**未レビュー**である。
  仕様上の正しさ（手掛かりの整合、書式）は保証するが、語感は保証しない
- クレジット画面の翻訳（§1.1 により対象外）
- 音声・字幕の読み上げ速度調整（文長がロケールで変わるため要調整だが別項目）

## 3. 設計

### 3.1 置き場所

`src/anoms.js` は書類と異変のデータ。UI 文言は関心が違うので **`src/ui.js` を新設**する。
規律は `anoms.js` と同じ：`assertLocale` で未知のロケールを弾き、既定値を持たない
（黙って日本語に落ちると、未訳が実機まで見つからない）。

`uiText(locale)` が入れ子のオブジェクトを返す。`index.html` の静的な文言は
`data-t="キー"` を持たせ、起動時に `game.js` が流し込む。HTML を含む文言は `data-th`。

### 3.2 暗証番号の手掛かり（最重要）

**手掛かりはロケールの正解と必ず一致していなければならない。** 正解は
`deadline(locale)` から決まる（`pinAnswerFor`）。

| locale | 期限 | 並び | 正解 | 手掛かり③が言及すべき日 |
|---|---|---|---|---|
| ja | 3/15 | MMDD | `0315` | 3月14日・15日 |
| en | 4/15 | MMDD | `0415` | April 14–15 |
| zh-Hans | 6/30 | MMDD | `0630` | 6月29日・30日 |
| ru | 30.04 | DDMM | `3004` | 29–30 апреля |
| es | 30.06 | DDMM | `3006` | 29–30 de junio |

「日付をそのまま並べただけ」という言い回しは、**ロケールの日付表記の並びに
従っていなければ嘘になる**。ru / es は日・月の順なので、そう書く。
ここが崩れると L-2（見えているものと結果が一致する）に反する。

### 3.3 日付は文言に直書きしない

物語の時間は「提出期限の日の 21:00 → 23:59」、期限後 END は「翌日 0:00」。
`3月15日` を各ロケールのファイルに直書きすると、`deadline()` を変えたときに
文言だけ古くなる。`ui.js` は `{deadline}` `{deadlineNext}` などの
**差し込み記号**を持ち、`game.js` が `deadline(locale)` から埋める。

同様に、氏名は `localeText(locale).playerName`、金額は `formatMoney(locale, n)`
を使う。**UI 側で数字を組み立てない。**

### 3.4 クレジット画面の扱い

`#credits` は日本語のまま。ただし**そこへ至るボタン**（ポーズの「クレジット」、
「戻る」）は UI なので翻訳する。中身が日本語であることは意図であり、
`index.html` にその旨のコメントを残す。

## 5. 実装記録（2026-08-28）

### 5.1 成果物

| 追加・変更 | 中身 |
|---|---|
| `src/ui.js`（新規, 約 800 行） | 5ロケール × 約 120 キーの UI 文言、差し込み（`fill`）、日付書式 |
| `index.html` | 静的文言を `data-t` に置換。**`#credits` の中身は触っていない** |
| `src/game.js` | `tr(key, extra)` で引く形に。`applyI18n()` が起動時に流し込む |
| `tests/unit/ui.test.js` | U-01〜U-16（15件） |
| `tools/charset.mjs` 経由 | 同梱フォントが **0.69MB → 0.47MB** に減った（§5.5） |

棚卸しの結果、翻訳対象は index.html 40 件 + game.js 83 件 = 123 件だった。
実装後に残った日本語は **index.html 3 件・game.js 3 件**で、すべて意図的：

- `言語 / Language` `日本語` `简体中文` ── 言語選択は各言語を自分の名前で出す
- `UI 文言のキーが無い: ${key}` ── 開発者向けの例外メッセージ
- GLSL シェーダのコメント ── 画面に出ない
- `青色申告` ── **これは見落としだった**。`mb.textContent` に残っていたのを修正済み

### 5.2 暗証番号の手掛かり（U-09〜U-12）の実測

全ロケールで、手掛かり③と正解が一致していることを確認した。

```
ja  正解=0315  日付は毎年、3月14日と15日に集中している。
en  正解=0415  Every year the dates cluster on April 14 and 15.
zh  正解=0630  日期每年都集中在6月29日和30日。
ru  正解=3004  Каждый год даты собираются на 29 и 30 апреля.
es  正解=3006  Cada año las fechas se concentran en el 29 y el 30 de junio.
```

ru / es は日→月の順なので `3004` / `3006`。手掛かりの文面も日→月で並ぶため、
「日付をそのまま並べただけ」という言い回しが嘘にならない（§3.2）。

氏名（`pinHint` が示す最後の一押し）も各ロケールで整合している：
April Fifteen / 六月 三十 / Апрелий Тридцатов / Junio Treinta。

### 5.3 設計上の判断

**`t` ではなく `tr` にした。** 最初 `t(key)` という名前にしたところ、
`game.js` には `const t = new THREE.CanvasTexture(cv)` のような**ローカル変数 `t` が
9箇所**あり、同じ関数スコープ内で `t("signPay")` を呼ぶと TDZ で
`Cannot access 't' before initialization` になった。看板の描画関数がまさにそれで、
**起動時に画面が真っ黒になる**。短い名前を共有名前空間に置かないこと。

**日付は「月を1回だけ」出す。** 当初 `{deadlinePrev}` `{deadlineDay}` に完全な日付を
入れていたが、日本語が「3月14日と3月15日」と冗長になった。`{mon}` `{d1}` `{d2}` に
分け、並べ方をロケールごとに決める形にした（ru は「29 и 30 апреля」と月が後ろ）。
**前日が同じ月にあることが前提**なので、期限が月初のロケールを足すときは
文言を作り直すこと（U-09 が `d.day >= 2` で見張る）。

**差し込み記号の正規表現が数字を取りこぼしていた。** `{[a-zA-Z]+}` だったため
`{d1}` に一致せず、**埋め忘れが例外にならず素通り**していた（画面に `{d1}` と出た）。
`{[a-zA-Z][a-zA-Z0-9]*}` に修正。埋め忘れを例外にする設計は、
正規表現が記号を拾えて初めて意味を持つ。

**結末の還付額を文言の上書きで作らない。** 元は `EDS.refund.text` を
走行ごとに日本語で組み立て直していた。そのままだと翻訳が効かないので、
`money` と `suffix` だけを差し替え、金額は `formatMoney(locale, n)` に任せる形にした。

**タイトルの英字副題はロケールで変える。** ja は既存デザインをそのまま残し、
en では `sub2` と同じ文が二重に出てしまうため、他ロケールは `KAKUSHIN` だけにした。

### 5.4 既存テストの差し替え

W-06 / W-09 / W-10 / W-13 / L-23 は「日本語の文字列が `game.js` にあること」を
検査していた。文言が `ui.js` へ移ったので、**検査先を移した**。
実装の都合で緩めたのではなく、要求（§1.1）が変わったことによる差し替えである。

L-23 は特に注意して移した。守る性質は「怪異の名前が開始前に必ず目に入ること」で、
`<h1>` が空になった今は (a) 器があること (b) `TXT.monster` を流し込む配線があること
(c) どのロケールでも名前が空でないこと、の3点で見る。

### 5.5 副次的な効果

日本語 UI が en / ru / es のサブセットから外れたため、同梱フォントが
**0.69MB → 0.47MB（-32%）**になった。P2-7 §5.7 に挙げていた積み残しが解消した。

### 5.6 積み残し

- **母語話者レビュー未実施。** 訳文は仕様上の正しさ（手掛かりの整合・書式・
  差し込み）は検証済みだが、語感は未検証。`anoms.js` と同じ状態である
- 字幕・通知の表示時間は日本語の文長に合わせたまま。ロシア語・スペイン語は
  文が長くなるので、`notice()` の秒数調整が要るかもしれない（実測していない）
- `<title>`（ブラウザのタブ名）は `anoms.js` の `title` から入れているが、
  HTML の静的な `<title>` は日本語のまま。起動後に上書きされる
