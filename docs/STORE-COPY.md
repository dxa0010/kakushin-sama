## 1. 短い説明（Short Description）

### 日本語

```
確定申告の締切は今夜23:59。部屋から5点の書類を集めて、e-Taxで提出しろ。
ただし、偽物が混じっている——存在しない年号、「魂」と書かれた金額、一字だけ違う氏名。
見抜けなければ却下される。そして書類を読んでいる間も、カクシン様は近づいてくる。
```

### English

```
Your tax return is due at 23:59 tonight. Find the five documents hidden in your
apartment and file them. But some are forgeries — a year that never existed, a sum
written as "soul", a name off by one letter. Miss one and you are rejected. And while
you are reading, KAKUSHIN is getting closer.
```

**なぜこの形か。** 一文目で締切（時限）、二文目で行動（集める・提出する）、
三文目で葛藤（偽物）、四文目で脅威（怪人）。**ジャンルの手掛かりを一文目に置かない**のは、
「確定申告」という語が既にフックとして強く、ホラーだと後から分かる方が引きが立つため。

## 2. About This Game

参照した構成は `The Exit 8`（同ジャンル・同規模・同じ日本設定で海外実況に届いた実例）。
**ルール → 概要 → プレイ時間 → 配信許諾 → オプション → 動作環境 → 著作権**の順で、
本作もこれに合わせる。プレイ時間と配信許諾を早い位置に置くのがこのジャンルの定石。

## 3. タグ（ユーザー定義タグ）

上位ほど効く。`The Exit 8` の実際のタグ順を土台に、本作固有のもの（Investigation / Comedy）を足した。

```
Horror, Psychological Horror, Puzzle, First-Person, Walking Simulator,
Atmospheric, Investigation, Mystery, Short, Singleplayer,
Surreal, Dark, Exploration, Replay Value, Difficult,
3D, Indie, Realistic, Comedy, Multiple Endings
```

- **`Comedy` を入れる。** 本作は「恐怖の文法とあるあるのギャップ」が売りで、
  純ホラーとして期待されると評価がずれる。`The Exit 8` も `Funny` を持っている
- **`Short` を隠さない。** 上の返金の整理と同じ理由
- **`Walking Simulator` は入れる。** ジャンル検索の入口として実際に機能している
- ⚠️ **`Anime` は入れない。** 本作の絵柄と噛み合わず、来た人が失望する

## 6. 入稿前に決めなければならないこと（P7-3・法務）

**`s5_etax.png` と About This Game の「e-Tax」表記は、商用化前に判断が要る。**

- 現状のスクリーンショットは **e-Tax の画面を模した UI**（「e-Tax（国税電子申告・納税システム）」の
  題字＋官公庁調の紺のクロム）を含んでいる
- `docs/HANDOFF.md` の権利方針は「実在の固有名詞はテキストとして言及するのみ。
  **ロゴや公式サイトの見た目を再現する方向には踏み込まない**」と明記している
- **ストアページの1枚として無料配布ではなく有料商品の宣伝に使うのは、この方針の外側にある**

取り得る道は3つ。**決めるのは利用者であって、実装側で黙って倒さないこと。**

1. そのまま出す（言及の範囲だと判断する）
2. **画面だけパロディ名に寄せる**（「ヨドバチカメラ」と同じ方針。`e-Tax` → 例えば `e-Zei`）。
   ゲーム内テキストの「e-Tax」言及は残してよい。**一貫性はこの案が最も高い**
3. スクリーンショットから外す（ゲーム内には残す）

同じ判断が「国税庁」「マイナンバーカード」にも掛かる。
本作の異変 `issuer`（発行元＝株式会社カクシン）は既にパロディ側の語彙なので、2案なら破綻しない。

## 7. 生成手順（再現用）

```bash
# 0) 静的サーバ（リポジトリルート）
python -m http.server 8765

# 1) スクリーンショット（1920x1080・HUDあり）
cp tools/shot-store.mjs "$APPDATA/npm/node_modules/"
cd "$APPDATA/npm/node_modules"
node shot-store.mjs --out C:/tmp/store              # 日本語
node shot-store.mjs --out C:/tmp/store-en --locale en

# 2) キーアート（agy＝Gemini。文字は描かせない）
#    ⚠️ **生成物は docs/storeart/ にコミット済み。作り直す必要は無い。**
#       agy は毎回違う画を返すので、同じ絵は二度と出ない。カプセルの下地は一次資料である。
#       差し替えたいときだけ下を回すこと。
node tools/genimage.mjs --out docs/storeart/key_16x9.jpg --aspect 16:9 --scene "..."
node tools/genimage.mjs --out docs/storeart/key_portrait.jpg --aspect 3:4 --scene \
  --conversation <前回のID> "..."          # 同じ画を継いで人物と光を揃える

# 3) カプセル合成（キーアート＋ロゴタイプ）
cp tools/make-capsules.mjs "$APPDATA/npm/node_modules/"
node make-capsules.mjs --out C:/tmp/store/capsules              # 日本語ロゴ（下地は docs/storeart/）
node make-capsules.mjs --out C:/tmp/store/capsules-en --locale en
```

**なぜロゴだけ別工程なのか。** `agy`（Gemini）は文字を描くと崩れる
（`tools/genimage.mjs` の実測メモ）。カプセルには「読める製品ロゴ」が Steam の必須要件なので、
**画像生成だけではカプセルが1枚も作れない**。下地を生成し、文字は headless Chromium で
ゲームと同じ同梱フォント（`assets/fonts/kakushin-serif-jp.woff2`）を使って重ねている。
