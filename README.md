# 確定申告からは逃げられない

ホラー×あるあるバカゲー（追跡型・一人称）。3月15日午後9時、確定申告書類を集めて期限までにe-Taxで送信するプロトタイプゲームです。ブラウザだけで動作します。

**▶ プレイ: https://dxa0010.github.io/kakushin-sama/**

## 概要

| 項目 | 内容 |
|---|---|
| ジャンル | ホラー×あるあるバカゲー（追跡型・一人称） |
| エンジン | Three.js r185（ES modules、vendor同梱・ビルドツール不要） |
| 現在の状態 | 遊べるプロトタイプ v8（主要家具のglTF化・洋室化） |
| 操作 | PC＝WASD＋マウス視点＋Eキー ／ スマホ＝2スティック（左＝移動／右＝視点） |

## リポジトリ構成

```
index.html                 エントリ（HTML/CSS/DOM、importmap）
src/game.js                ゲーム本体（ロジック＋レンダリング）
vendor/three/              Three.js r185 本体＋addons（postprocessing、GLTFLoader等）
assets/textures/           実写テクスチャ（three.js examples由来のMIT素材＋ambientCG由来のCC0素材）
assets/models/              主要家具のglTFモデル（Poly Haven由来、CC0）
.github/workflows/         GitHub Pages 自動デプロイ
```

プッシュするだけで GitHub Actions が Pages へ自動デプロイします。ローカル確認は `python3 -m http.server` などの静的サーバでOK（ES modules のため `file://` 直開きは不可）。

**開発を引き継ぐ場合は先に [`docs/HANDOFF.md`](docs/HANDOFF.md) を読むこと。** 今回のグラフィックス刷新で何をどう変えたか・ハマった箇所・外部アセットの制約・次にやるべき作業の優先順位がまとまっている。

## 原点：なぜこの企画か

「儲かるAndroidアプリ」の市場調査が出発点。個人開発×AI×サブスクの職業特化ツールをいくつか検討した末、「確定申告の恐怖」というテーマ自体が日本のフリーランス全員に刺さる普遍的なあるあるであることに行き着いた。ASOで地道に積み上げる路線とは別に、**SNSバイラルで一気に跳ねる路線**としてゲーム化を選んだ。

5案（レシート雪崩サバイバル／ホラー追跡／弾幕回避RPG風／積み上げパズル／無限ランナー）の中から本作を選んだ理由：

- 低ポリ＋暗い照明はThree.jsの得意分野で、個人開発でも「それっぽい絵」が出しやすい（アセットの粗が闇に隠れる）
- 8番出口・Chilla's Art的な実況/切り抜き動画の導線にそのまま乗れるジャンル
- 毎年2〜3月に確実に話題が再燃する季節性コンテンツ。一度作れば毎年バズのチャンスが巡る

## 面白さの核

v3までは「怪人から逃げる」が主語だったが、v4で大きく転換した。**8番出口**を参照点に、遊びの主語を「逃げる」から「見抜く」へ移し、怪人は常時ではなく**イレギュラーな恐怖イベント**として再配置している。

### 柱1：恐怖の文法とあるあるのギャップ

ホラー様式（暗い廊下・足音・静寂）を完全に真顔でやりきった上で、中身だけが事務作業という落差が笑いを生む。ゲーム側は一切ボケない・ふざけない。ふざけているのは題材だけ。

### 柱2：思考が主役、カクシン様はイレギュラー

本編は書類の真贋判定。拾う前に検分ビューで拡大し、16種の異変プール（存在しない年号・逆さの印・鏡文字・透かしの顔など）から抽選された「どこか一箇所ありえない」を見抜いて、受理／破棄を判断する。**正誤は即座に教えない**——「あの判断、合っていたのか」という疑いを持ち歩かせるのが狙い。怪人は常時徘徊をやめ、前触れ（TVノイズ・照明の明滅・時計の故障・壁のポスターの変化）→出現→短い狩り→退場、という「訪問」イベントに変更。前触れに気づけば、出現前にクローゼットへ逃げ込める。破棄や却下は次の訪問を早める。

### 柱3：配信適性と周回設計

e-Tax送信のリトライ地獄（偽物を名指しで却下）は健在。加えて、異変図鑑・リザルトでの答え合わせ・判定ランク（S〜D）・高難度モード「青色申告」で、1回きりで終わらない設計にした。

### やらないことリスト

- 本格ステルスゲー化しない（1周15〜30分、難易度で唸らせない）
- 説教・実用知識を入れない（教育臭は冷める）
- あるあるの水増しをしない（全員が経験するネタだけに絞る）
- 判定の正誤をその場で教えない（次のe-Taxまで疑いを持ち歩かせる）

### 異変プール（抜粋、全16種）

各書類は検分すると本物／偽物のどちらかで、偽物には16種の異変プールからランダムで一つ仕込まれる（わかりやすい系／巧妙系の2段階。青色申告モードは巧妙系の出現率が高い）。

| 異変 | 内容 | 審査時の却下文言 | 難度 |
|---|---|---|---|
| 存在しない年号 | 「令和∞年分」「昭和107年分」 | 年号が存在しません | |
| 入れ替わった題字 | 書類名の1・2文字目が入れ替わる | 書類の名称に誤りがあります | 巧妙 |
| 負の金額 | 金額欄が「−¥184,320」 | 金額が負の値になっています | |
| 逆さの印 | 朱肉の印影が180°回転 | 押印が逆さまです | 巧妙 |
| 一字ちがいの氏名 | 「三月 十五」→「三月 十六」 | 氏名が申告者と一致しません | 巧妙 |
| 鏡の書類 | 書類全体が左右反転 | 書類全体が鏡文字です | |
| 実在しない発行元 | 発行元が「株式会社カクシン」 | 発行元が実在しません | |
| 存在しない日付 | 「令和8年2月30日」 | 発行日が存在しません | 巧妙 |
| 魂の対価 | 金額欄が「魂」 | 金額が通貨ではありません | |
| 四づくし | 数値が全て4に置き換わる | 数値がすべて4です | |
| 名乗る書類 | 氏名欄が「カクシン様」 | 氏名が人間ではありません | |
| 見ている印 | 朱印の中身が目玉 | 印影が瞬きしました | |
| 濡れた文字 | 文字がにじんでいる | 書類が濡れています | |
| 透かしの顔 | 紙にうっすらとあの顔 | 不正な透かしが検出されました | 巧妙 |
| 朱の呪 | 左上に赤い「呪」の文字 | 確認できない印が押されています | |
| 化けた項目名 | 項目名の1文字が類似字に置換（金→全 等） | 項目名に誤りがあります | 巧妙 |

## 実装状況（v8時点）

技術構成：Three.js r185、ES modules構成（`index.html` + `src/game.js` + `vendor/three/`、importmap使用、ビルドツールなし）。GitHub Pages上で公開中。

### 家具・部屋のglTF化と洋室化（v8で追加）

- 主要家具7点を手続き型ジオメトリから実写PBRのglTFモデル（Poly Haven、CC0）に置換：壁掛け時計・本棚・テレビ・PCデスク・椅子・タンス・ベッドフレーム
- 舞台を和室設定から洋室（フローリング＋洋家具）に統一。畳・ふすまのプロシージャルテクスチャは廃止し、押入れは見た目を洋風クローゼットの開き戸に変更（隠れ場所としてのゲームロジック・当たり判定は不変。表示テキストも「押入れ」→「クローゼット」に統一）
- 壁掛け時計は文字盤モデル内の分針・時針メッシュ自体をゲーム内時刻に同期して回転させる方式に変更（旧: Canvas再描画→新: メッシュ回転）。時計故障演出（`clockGlitch`）もそのまま対応
- 各モデルは出典元によって色温度・彩度がばらつくため、共通のティント処理（`tintModel()`）で部屋の暗いウォームトーンへ統一
- `GLTFLoader`（vendor同梱済みだったが今回初配線）で非同期ロード。当たり判定は同期的に別途AABBを登録するため、モデルの読み込み中も衝突判定は機能する

### グラフィックス（v7）

- 全ルームライト・懐中電灯にシャドウマッピング（PCFSoft）。物理光量単位（r155+）へのスケール移行込み
- ACESフィルミックトーンマッピング＋ポストプロセス（ブルーム／ビネット／フィルムグレイン／色収差、自作シェーダーパス1本にまとめて軽量化）
- 全マテリアルをMeshStandardMaterialへ移行し、プロシージャルテクスチャの輝度から法線マップを自動生成。RoomEnvironmentによる弱いIBLで金属・光沢面に反射
- 床・壁は実写PBRテクスチャに置換（hardwood2はthree.js examples由来のMIT、壁のplaster017はambientCG由来のCC0）

### 実装済み（v6まで）

- 自宅マップ（玄関・リビング・キッチン・寝室・クローゼット）と壁・家具の衝突判定
- 書類検分システム：拾う前に拡大検分し受理／破棄を判断。正誤は即座に表示しない
- 異変プール16種（わかりやすい系／巧妙系の2段階、モードで出現比率が変化）
- e-Tax審査：偽物を持っていると異変を名指しで却下し、書類を部屋へ差し戻す。全部本物なら一発受理
- 怪人「カクシン様」の訪問イベント化：前触れ（TV／照明／時計故障／ポスター）→出現→短い狩り→退場。常時徘徊は廃止
- 3フェーズの時計進行（22:00照明低下／23:00 BGM停止／23:59タイムアウト）と連動した訪問間隔の短縮
- 異変図鑑・エンディング記録・最高ランクをlocalStorageに永続化、タイトル画面に表示
- リザルトの答え合わせ：今夜の全判定を○×で開示。見抜けなかった偽物は〈？？？〉のまま伏せる
- 判定ランク（S国税査察官〜D駆け込み申告者）、還付金額は判定精度で変動
- 高難度モード「青色申告」（還付ENDで解禁。偽物3枚保証・巧妙な異変偏重・時計高速・訪問が早く長い）
- クローゼットに隠れるメカニクス（隠れている間も時計は進む／至近距離では隠れ不可）
- ミニマップ（壁・家具の構造、向き付きプレイヤーマーカー、怪人は追跡中のみ表示）

## 変更履歴

- **v1 初回プロトタイプ**：基本ループ（探索→収集→e-Tax送信→エンディング）が完成。PC操作のみ。
- **v2 モバイル対応・逃げ道の整備**：タッチ操作を2スティック化。押入れに隠れる機構を追加。追跡速度・視線切り猶予・プレイヤー速度を調整。
- **v3 ミニマップ・探索猶予・難易度緩和**：部屋構造を表示するミニマップを追加。開始15秒の探索猶予とランダム出現演出を実装。全体的に易化。
- **v4 思考中心のゲーム性へ転換**：8番出口を参照点に核を再設計。書類の真贋を見抜く検分システムを本編に据え、常時徘徊していた怪人を前触れ付きの訪問イベントへ変更。異変8種を実装。
- **v5 周回プレイの仕組み**：異変プールを16種に倍増し、正しく見抜いた異変を図鑑としてlocalStorageに永続化。リザルトに答え合わせ表示、判定ランク、高難度モード「青色申告」を追加。
- **v6 部屋のビジュアルをリアル寄りに全面作り込み**：Canvasによるプロシージャルテクスチャ（畳・フローリング・漆喰壁・ふすま・夜景）と家具のディテール化を実施。当たり判定・ゲームバランスは不変。
- **v7 グラフィックス基盤刷新**：Three.js r128→r185へ更新し単一HTMLをES modules構成に分割。全光源のシャドウマッピング（PCFSoft）、ACESフィルミックトーンマッピング、ポストプロセス（ブルーム・ビネット・フィルムグレイン・色収差）、マテリアルのPBR化（MeshStandardMaterial＋プロシージャル法線マップ自動生成）、床の実写テクスチャ化（hardwood2、three.js examples/MIT）。続けて壁・畳・布も実写PBR化（PaintedPlaster017 / Tatami005 / Fabric001、ambientCG/CC0）。GitHub Pages公開開始。
- **v8 家具のglTF化・洋室化（現行）**：`GLTFLoader`を配線し、壁掛け時計・本棚・テレビ・PCデスク・椅子・タンス・ベッドフレームの7点を実写PBRのglTFモデル（Poly Haven、CC0）に置換。舞台を和室から洋室に統一（畳→フローリング、押入れ→クローゼットの見た目変更。ゲームロジック・当たり判定は不変）。壁掛け時計は針メッシュ自体を回転させる方式に変更し、モデル間の色味を共通ティントで統一。

## 次のステップ候補・未解決の論点

- **ビジュアル**：怪人本体のモデル強化。部屋は作り込んだが、カクシン様自体は円柱＋Canvas顔テクスチャのまま。訪問イベント化で登場頻度は下がった分、出てきた時の一体としての説得力を上げる余地がある。
- **バランス**：異変の見つけやすさと訪問頻度。図鑑の埋まり方（1周2〜4個ペースを想定）と、白色／青色それぞれの訪問間隔・huntLeftが体感と合っているか、実プレイでの再検証が必要。
- **技術**：Androidへの載せ方。WebView/TWAでラップしてPlayストアに出すか、まずWebゲーム（itch.io / Poki等）として公開しバズらせてからアプリ化するか。バイラル狙いなら後者を推奨（URL一発で遊べる状態の方が拡散効率が高い）。
- **収益化**：広告＋買い切りの広告除去。インタースティシャル＋リワード広告を基本に、広告除去を¥300程度の買い切りで提供する案。ゲームのサブスクは個人開発では定着しにくいため見送り。
- **マーケ**：季節性を活かしたローンチタイミング。確定申告シーズン（2〜3月）に合わせて公開・実況者への訴求を狙う。毎年再燃するテーマなので複数年にわたって波を作れる。
- **未実装**：市役所END。マイナ暗証番号3回ミスで分岐する4つ目のエンディング。設計はあるが未着手。
